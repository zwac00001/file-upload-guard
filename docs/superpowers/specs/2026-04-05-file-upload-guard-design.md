# File Upload Guard Design

Universal `skill + local helper script` flow for local project analysis without raw file uploads.

- Applies across `codebuddyAgent`, Codex App, and other compatible platforms.
- Uses summary-first project analysis, then file summaries, then page-on-demand content.
- Preserves original text in v1.
- Supports PDF and Word text extraction.
- Treats the workflow as mandatory for local project and file analysis tasks.
